# 📰 InfoStream Media – News Aggregator

InfoStream Media is a web-based news aggregator application developed using **Python Flask**. It integrates NewsAPI to retrieve news articles from different categories and provides users with a centralized platform to discover and browse news.

The application includes keyword searching, category filtering, pagination, saved articles, dark mode and a responsive user interface.

## ✨ Features

- **News Aggregation:** Retrieve news articles dynamically using NewsAPI.
- **Category Filtering:** Browse news across different categories.
- **Keyword Search:** Search for specific news topics.
- **Pagination:** Navigate through multiple pages of news articles.
- **Saved Articles:** Bookmark interesting articles using browser LocalStorage.
- **Dark Mode:** Switch between light and dark themes.
- **Article Extraction:** Use Newspaper3k to retrieve additional article content where available.
- **Responsive Design:** Support desktop, tablet and mobile screen sizes.
- **Error Handling:** Handle API errors, request timeouts and article extraction failures.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd article_app
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

Activate the virtual environment:

**Windows:**
```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure the NewsAPI key

Create a `.env` file in the project root directory:

```env
NEWSAPI_KEY=your_newsapi_api_key
NEWSAPI_COUNTRY=us
```

Replace `your_newsapi_api_key` with your actual API key from [NewsAPI](https://newsapi.org/).

**Important:** Do not upload your `.env` file or expose your API key on GitHub.

### 6. Run the application

```bash
python app.py
```

Open your browser and navigate to:

```text
http://127.0.0.1:5000
```

## 🧪 Testing

The application includes planned unit testing using pytest to verify backend functionality.

Install pytest:

```bash
pip install pytest
```

Run the test suite:

```bash
pytest -v
```

Testing scenarios include:

- Successful news retrieval.
- Missing or invalid API key.
- Invalid news category.
- Invalid pagination input.
- Keyword search functionality.
- Empty API responses.
- Request timeout handling.
- Invalid article URLs.
- Article extraction failures.
- Missing article information.

## 🌐 Deployment

The application can be exposed to the internet using **ngrok**, which creates a secure HTTPS tunnel to the locally running Flask server.

```bash
ngrok http 5000
```

Use the HTTPS forwarding URL generated by ngrok to access the application externally.

*Note: The local Flask server must remain running while the ngrok tunnel is active.*
